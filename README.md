# Agentic Financial Operations Assistant

## Overview

An AI-powered financial operations assistant built using FastAPI, React, PostgreSQL, and SQLAlchemy.

## Tech Stack

- React + Vite
- FastAPI
- PostgreSQL
- SQLAlchemy
- Python
- Git

## Features

- User Management
- PostgreSQL Database
- REST API
- AI Agent Architecture (In Progress)

## Project Structure

```
AgenticFinancialAssistant/
│
├── frontend/
├── backend/
├── database/
└── docs/
```

## Run

Frontend

```bash
npm install
npm run dev
```

Backend

```bash
cd backend
.\venv\Scripts\Activate.ps1
uvicorn main:app --reload
```
